# ✦ ABOUT GHEA

**GHEA BOT** adalah project WhatsApp Multi-Device yang dikembangkan dengan konsep modern, modular, dan expandable.

GHEA dirancang bukan hanya sebagai kumpulan command, tetapi sebagai sebuah sistem bot yang dapat terus dikembangkan mengikuti kebutuhan project.

> **GHEA — built for a better WhatsApp bot experience.**

---

# ♡ WHY GHEA?

GHEA membawa pendekatan yang lebih terstruktur:

- **Clean Architecture** — sistem dibuat agar lebih mudah dipahami.
- **Expandable System** — fitur baru dapat terus ditambahkan.
- **Multi-Device** — dirancang untuk ekosistem WhatsApp Multi-Device.
- **Flexible Configuration** — konfigurasi dapat disesuaikan.
- **API Ready** — dapat dikembangkan dengan layanan API eksternal.
- **Modern Experience** — menu dan interaksi dibuat lebih nyaman.
